# You Are Loved — Book Funnel

Funnel assets and build guide for **"You Are Loved — When Faith Feels Complicated"** by Joelle Merschman.

- Domain: `faithfirstleadership.com`
- Platform: GoHighLevel (GHL) Funnels
- Email: ConvertKit (Kit)
- Sales path: Free chapter opt-in → ConvertKit nurture → Amazon paperback ($34.99)

## Tone guardrails

- Warm, plain-language, hopeful. No theological jargon.
- No politically coded language. No "us vs. them."
- Affirming to deconstructing Christians, spiritually curious "nones," hurting believers, and LGBTQ+/marginalized readers.
- No hypey marketing pressure ("act now," fake scarcity).
